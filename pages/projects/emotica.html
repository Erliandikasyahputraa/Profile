ML-POWERED INDONESIAN SENTIMENT ANALYSIS PLATFORM · 2025

Emotica

ML-powered Indonesian text sentiment analysis web platform turning NLP models into a modular, interactive user experience.

THE PROBLEM

Content creators, online sellers, and young audiences struggle to quickly analyze and understand emotional tones and audience feedback from unstructured Indonesian text.

WHY I BUILT IT

Developed for MBKM DBS Coding Camp 2025 to productize an NLP pipeline into a fast, user-facing web application with real-time visualization and history tracking.

THE SOLUTION

Full 3-tier architecture: Modular Next.js/Vite frontend connected via REST API to a Flask backend and an Indonesian sentiment classification model (Bi-LSTM + Attention & BERT).

MY ROLE

Front-End Lead

ARCHITECTURE & DECISIONS

Led the frontend engineering team in building a responsive, accessible interface with Chart.js analytics, dark mode, pagination, and modular ES6 state management. Coordinated RESTful API integration with the Flask backend and ML inference pipeline.

TECH STACK & TOOLS

Next.jsTailwind CSSJavaScript ES6Chart.jsFlaskPythonTensorFlowKerasBi-LSTMMongoDB

WHY THIS TECH STACK

Bi-LSTM + Attention & BERTAccurately captures nuanced Indonesian slang and context-dependent emotional polarity.
Flask REST APILightweight, low-overhead microservice wrapping Python model inference with fast JSON responses.
